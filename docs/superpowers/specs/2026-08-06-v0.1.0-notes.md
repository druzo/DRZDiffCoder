# DRZ Diff v0.1.0 — Release Notes

> **Release date:** 2026-08-06 &nbsp;·&nbsp; **Base commit:** `f3c42c5` &nbsp;·&nbsp; **Tag:** `release/v0.10`
> **Scope:** 50 commits · 6 crates · 6,657 lines of Rust · 22 languages · 5 platform artifacts

---

## 🎉 Executive Summary

**DRZ Diff v0.1.0 is the first public release of a source-code diff and merge tool engineered for developers who care about both fidelity and fluidity.** It pairs a `rope`-backed document model with **tree-sitter's true incremental reparse**, so editing a single character on a 10,000-line file does not trigger a full re-parse — only the affected sub-tree is rebuilt and only the dirty lines are re-laid out.

The codebase is organised as a strict **MVVM cargo workspace** (`drz-core` · `drz-highlight` · `drz-viewmodel` · `drz-editor` · `drz-diff-ui` · `drz-app`) — a deliberate choice that lets every merge / diff / highlight decision be unit-tested headlessly without spinning up a GUI. The view layer is pure `egui`, the view-model layer has zero `egui` imports, and the model layer has zero `eframe` awareness.

This release ships **22 languages** out of the box (Rust, Python, JavaScript/JSX, C, C++, Java, C#, SQL, R, Pascal, Go, Assembly, PHP, Kotlin, Dart, Lua, Julia, Lisp, Scala, Objective-C, Swift, JSON) plus plain-text fallback, and produces **installable artifacts for five platforms**: Windows x86_64 (`.msi` + `.exe`), macOS Intel (`.dmg` + `.app`), macOS Apple Silicon (`.dmg` + `.app`), Linux x86_64 (`.deb` + `.AppImage`), and Linux arm64 (`.deb`). All five share one pipeline (`scripts/release.sh`) that is idempotent, CI-friendly, and driven entirely by a Conventional Commits history.

**Why it matters:** for the first time, DRZ Diff delivers a free, offline, language-aware, merge-friendly diff tool that feels native on every desktop OS without dragging in `syntect` (regex-based) or `egui_code_editor` (non-structural). The release pipeline is reproducible end-to-end, every artifact is SHA-256-verified, and the next iteration (3-way merge) has a clear runway.

## 🆕 New Features

### Core (`drz-core`)

- **`Document` rope buffer** — `ropey`-backed, `O(log n)` edits, every mutation emits exactly one `tree_sitter::InputEdit` (`f80c57f`).
- **File I/O with safety guards** — UTF-8 with `chardetng` fallback, binary detection (NUL in first 8 KB → refuse with message), 50 MB size cap (`18f5aec`).
- **Line diff via `similar`** — Myers + histogram algorithm, `Hunk` model (`3555161`).
- **Pane alignment builder** — virtual padding rows so equal blocks line up across panes (`ee7ab4a`).
- **Char-level inline diff** — character run sub-highlights inside modified lines (`89fb3c7`).

### Highlighting (`drz-highlight`)

- **tree-sitter engine** — full parse + per-line `LayoutJob` spans (`7c5aa1c`).
- **Incremental reparse via `InputEdit`** — only the dirty sub-tree is touched (`4143382`).
- **Language detection + style model** — 22 grammars + plain-text fallback (`7960a61`).

### ViewModel (`drz-viewmodel`)

- **`EditorViewModel`** — bridges document + highlight engine (`7aa488b`).
- **`DiffViewModel`** — async debounced diff computation, channel-fed result drain, chunk-merge command (`1ef13ab`).
- **`AppViewModel`** — `open_pair_command`, save, error surface, repaint callback injection (`d716489`).
- **`Selection` shared type** + `text_in_range` / `replace_selection_with` (`d702fe4`, `e4a7af7`).

### View (`drz-editor`)

- **`CodeEditor` widget** — gutter, styled lines, cursor, key input, char-boundary snap (`0eed493`, `df0720e`).
- **Mouse selection + word/line** — double-click selects word, triple-click selects line, drag extends range (`93f099a`).
- **Keyboard selection + clipboard** — Shift-arrows, Shift-Home/End, `Ctrl+A/C/X/V` (`69a37a7`, `31a7a74`, `9609e83`).
- **Right-click context menu with icons** — Cut / Copy / Paste / Select All, vector icons recoloured to brand stroke (`7a4e03c`, `7c5a111`, `710a487`).
- **Selection highlight rendering** — visual feedback during drag-select (`dbec1fe`).

### View (`drz-diff-ui`)

- **Synced side-by-side panes** with **change-band center strip** (Phase-1 connector strategy) (`ab1a82d`, `8479335`).
- **Merge arrows** in the center strip → click to copy hunk across panes.
- **Per-line red/green backgrounds + char-level inline emphasis** (`fd4c791`, `fe3568b`).
- **PNG icons for merge arrow buttons** (`37599c7`).

### View (`drz-app` shell)

- **Welcome screen** — centered brand icon, primary CTA, drag-and-drop file pair anywhere on the window (`74eddd9`, `6fcc742`).
- **CLI entry** — `drzdiff <left> <right>` works as `git difftool`/`git mergetool` without a wrapper script.
- **Window shell** — menu, error banner, repaint callback wiring (`dc75922`).
- **Theme toggle** (dark default / light), persisted in `eframe::Storage` under key `drz_theme_dark` (`74eddd9`).
- **Linux desktop integration** — writes `.desktop` entry + hicolor icon sizes on first run so Wayland taskbar resolves the brand icon (`crates/drz-app/src/icon.rs`).

### Release pipeline (`scripts/release/`)

- **Single-command cross-platform build** — `./scripts/release.sh` produces every installer.
- **Windows** — `mingw-w64` cross-compile, `cargo-wix` produces `.msi` with embedded `.ico`, PE resource table populated via the new `winresource` build script (`crates/drz-app/build.rs`).
- **macOS Intel + Apple Silicon** — `osxcross` (clang wrappers), bundled `.app` with `Info.plist` + `AppIcon.icns`, hybrid ISO9660/HFS+ wrapped in a `koly` DMG via `genisoimage` + `libdmg-hfsplus`.
- **Linux x86_64** — `.deb` (assembled with `dpkg-deb` + `fakeroot`) and `.AppImage` (via legacy `appimagetool`).
- **Linux arm64** — `.deb` for Asahi / Pi 5 / Graviton.
- **Native icon embedding**:
  - Windows — `.ico` embedded in PE via `winresource`.
  - macOS — `.icns` (icp4/icp5/icp6/ic07/ic08/ic09) generated from `AppIcon.png` via Python + PIL.
  - Linux — PNG-in-binary (existing) + hicolor icons in `.deb` + AppImage.
- **GitHub Actions** — `.github/workflows/release.yml` triggers on `v*` tag → installs prereqs via `sudo ./scripts/release/install-prereqs.sh` → uploads artifacts via `softprops/action-gh-release@v2` (`c2f1951`, release pipeline commits).

## ♻️ Refactoring

- **MVVM enforcement** — `drz-viewmodel` has zero `egui`/`eframe` imports; view crates never touch `ropey` / `tree-sitter` / `similar` directly. Repaint signalling flows through an injected `Arc<dyn Fn()>` callback wired at the app shell.
- **Spec correction** — connector polygons between panes were demoted to Phase 2; Phase 1 uses the simpler center-strip change bands (`8479335`).
- **CI** — test matrix expanded to linux/windows/macos (`c2f1951`).
- **CLI smoke tests** via `assert_cmd` (`96f551b`).
- **Shared `replace_lines` edit primitive** — collapse the left/right variants in `drz-core` into one (`161dca5`).

## ⚠️ Known Limitations

- **Windows `.msi` build on Linux + Wine** — WiX `light.exe` throws `LGHT0216 / Win32 0x65B` under Wine (cabinet-extractor incompatibility). The pipeline falls back to a direct-copy `install.bat`. CI on a Windows runner builds the `.msi` cleanly via the same script.
- **No code signing** — Windows binaries are unsigned (SmartScreen warning on first run), macOS binaries are ad-hoc signed only (`codesign --sign -` → Gatekeeper warning on first run), `.deb` and `.rpm` are unsigned.
- **macOS SDK is community-mirrored** — `MacOSX11.3.sdk.tar.xz` is fetched from `phracker/MacOSX-SDKs` (legal grey area; Apple does not redistribute). For ToS-clean builds, use a macOS host with Xcode.
- **No RPM** — `rpmbuild` is not in apt and we did not invest in it for v0.1.0.
- **No universal macOS binary** — `.app` per arch; user picks the right `.dmg`.
- **Phase 2/3 features deferred** — see Roadmap.
